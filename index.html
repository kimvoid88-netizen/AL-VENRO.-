HTML هي اللغة المسؤولة عن إنشاء هيكل الصفحة ومحتواها، مثل العناوين والنصوص والصور والأزرار. فعلى سبيل المثال، عند إنشاء عنوان أو إضافة صورة داخل الموقع فإن ذلك يتم باستخدام HTML.

CSS هي اللغة المسؤولة عن تصميم الموقع وتنسيقه. من خلالها يمكن تغيير الألوان والخلفيات وأحجام الخطوط ومواقع العناصر داخل الصفحة، مما يجعل الموقع أكثر جمالًا وتنظيمًا.

JavaScript هي اللغة المسؤولة عن التفاعل داخل الموقع. يمكن استخدامها لإظهار رسائل عند الضغط على الأزرار أو تحديث محتوى الصفحة أو تنفيذ العديد من الوظائف الأخرى التي تجعل الموقع أكثر حيوية.

الـ Front-End هو الجزء الذي يراه المستخدم ويتعامل معه بشكل مباشر، ويتكون بشكل أساسي من HTML وCSS وJavaScript.

الـ Back-End هو الجزء الذي يعمل خلف الكواليس، وهو المسؤول عن معالجة البيانات والتعامل مع قواعد البيانات وتسجيل الدخول وإدارة المعلومات المختلفة داخل الموقع.

الدومين (Domain) هو عنوان الموقع الذي يكتبه المستخدم للوصول إليه، مثل google.com. أما الاستضافة (Hosting) فهي المكان الذي تُخزن فيه ملفات الموقع حتى تصبح متاحة على الإنترنت.

الموقع الثابت (Static Website) يعرض نفس المحتوى لجميع الزوار ولا يتغير إلا عند تعديل ملفات الموقع. أما الموقع الديناميكي (Dynamic Website) فيمكن أن يعرض محتوى مختلفًا حسب المستخدم أو البيانات المخزنة في قاعدة البيانات.

من أشهر خدمات الاستضافة المجانية: Vercel و Netlify و GitHub Pages، وهي خدمات تسمح برفع المواقع ونشرها على الإنترنت بسهولة.
